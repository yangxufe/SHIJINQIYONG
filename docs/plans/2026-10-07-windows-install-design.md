# Windows 下载即运行与账号闭环

用户授权自动安装基础环境及完善登录注册。保留 Django 认证、邀请制、现有 UI 和真实数据。对比依赖手工安装、要求 Docker 和原生自动安装，本轮采用原生 PowerShell 引导 + Python 运行控制器：不需要 Git、Node、Docker 或预装 Python，ZIP 解压后双击 Start-Windows.cmd。

面向 Windows 10/11 x64；先检查架构和受管策略，不能承诺任意操作系统/企业限制下都可安装。官方 Python 3.13 与 Caddy 下载固定版本及官方散列（Python SHA-256、Caddy SHA-512）；Python 可执行文件首次另验 Authenticode。安装依赖锁，YOLO 复用仓库模型并校验。下载失败可重试，不能无校验执行或降级安全。

运行文件在当前用户 LOCALAPPDATA/ShiJinQiYong，ACL 限本人与 SYSTEM；源码可移到新目录，数据库、附件、配置与 CA 不随源码重建。单实例锁覆盖部署和运行；依赖以锁文件散列分目录，失败不破坏旧环境。迁移前完整备份，已有账号不重置。旧 data/runtime.env 安装单独提示，不自动复制或接管。

默认 Caddy localhost HTTPS，Waitress loopback 独立空闲端口。首次以本机控制台输入管理员和密码，不提供未认证网页抢占入口。保存家庭时区并要求确认，禁止默认密码。增加 Django 原密码校验的本人改密和明确恢复指引；其他成员继续 24 小时一次性邀请码注册。可撤销未用邀请。

局域网模式单独选择实际网卡并确认可信，按精确 IP/子网/接口/程序/端口配置防火墙，需要 UAC 时由操作者确认。首次本机 CA 信任显示指纹并交由用户确认，不自动降低证书校验；手机信任仍属人工步骤。关闭运行窗口停止本轮创建的子进程，不能误杀旧实例。

验证：账号/CSRF/邀请失效/会话回归，配置和端口边界，PS5.1 解析与下载校验，独立目录从零安装依赖/迁移/备份/HTTPS 健康检查/重复启动/退出清理。真实另一台空白 Windows、UAC、手机 CA 分列未执行，不宣称完整实机验收。

实施调整：在当前 MSIX 宿主中实测官方 Python MSI 缓存路径不可用（0x80070003），改用 Python 官方文档推荐的 NuGet CPython 发行包，固定 3.13.16、SHA-256 并验证 Python Software Foundation 数字签名。直接解包提供 venv/pip，不使用嵌入式发行版、不修改 PATH/注册表。当前宿主的目录重定向须记录，不能据此声称另一台空白 Windows 已实测。
