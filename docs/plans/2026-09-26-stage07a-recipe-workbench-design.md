# 阶段 07A 菜谱工作台实施设计

原项目已有可用批次过滤、六道名称式内置菜谱、家庭共享菜谱、实际用量扣库存和采购幂等服务。本阶段沿用这些 ID、权限和写服务。开发前保存 `outputs/stage07a-before-source.zip`，停止 Waitress 后通过 `backup_household` 备份私有数据库与附件。

1. 先补结构化材料、份数、器材、时间、分步教程与审核状态。旧家庭菜谱默认“用量待补”，仍可查看和手工记录真实使用，不展示虚假的严格数量匹配。内置菜谱保留原 ID，逐条补结构数据和来源。
2. 本地匹配读取 `usable_lots()`、真实数量和版本；仅 g/kg、ml/l 做精确同维换算，件/包不换算克。候选各自评估，选定菜单共用一份剩余库存。排序原因、批次预计用量与缺口由服务器计算。采购需再次确认，实际做饭需重新核查并调用原库存动作。
3. 个人配置与家庭默认配置分开；个人硬限制只在本人或明确分享给本餐时读取。营养映射保留 FDC 来源 ID 与数据状态，字段缺失保持未知；标签注明相对排序或用户目标，不当成医学建议。
4. 自然语言只提取明确出现的有限条件，展示可编辑摘要后确认。未识别内容保留为原文，不擅自将健身理解为减脂或将高碳水改为低碳水。冲突和无解不放松硬条件。
5. AI 采用单个本机工作进程、SQLite 任务表和可配置 Provider。默认关闭，外部发送需管理员启用且用户对本次数据授权。失败、超时、取消与失联任务真实显示；没有凭据或实际调用证据时标记“真实模型未联调”。

安全依据：营养值以 [USDA FoodData Central](https://fdc.nal.usda.gov/api-spec/fdc_api.html) 的可追溯记录为基准；肉禽熟度规则引用 [USDA FSIS 安全中心温度表](https://www.fsis.usda.gov/food-safety/safe-food-handling-and-preparation/food-safety-basics/safe-temperature-chart)。这些资料不代替家庭成员核对食材状态或真实设备验证。
