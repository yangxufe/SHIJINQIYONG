# 阶段 07A 安全核对

## 2026-10-07 Windows 安装与账号边界

默认本机 HTTPS、准确 Host/Origin、Secure 会话/CSRF Cookie、CSP/no-store 均保持。首个管理员通过本机交互和 Django 表单创建，无默认密码、匿名网页管理员入口或新密码机制。本人改密核对原密码；普通成员不能发/撤销邀请；邀请码使用/过期/撤销后失效。密码恢复仅本机，不需要上传数据库。

安装包固定官方来源和 SHA；CPython 首次验证 Python Software Foundation 数字签名，后续从已校验归档比较可执行文件散列，避免离线运行依赖证书联网检查。Caddy 同样比较官方归档中的程序。若缺少 VC++，使用 Microsoft 官方包并验证签名；公司策略/UAC 拒绝就停止。此流程不禁用杀毒/防火墙或 TLS，不修改全局 PATH/PowerShell 执行策略。

私有根目录限制为当前用户与 SYSTEM；数据/CA/配置不在 static、不在源码包。旧部署与新目录独立。LAN 每次明确确认，后端始终 loopback；CA 信任另外提示，不能以健康检查替代浏览器/手机信任。安装证书、防火墙 UAC 和真实另一台 Windows/手机测试均需独立记录；本轮未执行这些系统授权动作。

- 生成、浏览、反馈和保存不写库存或购物项；菜单采购需显式选择净缺口，库存动作需再次确认实际量并通过原事务、条件更新和流水。任务 UUID、个人配置、结果页无共享缓存。消费者取消任务后不发布迟到结果；外部供应商可能仍已计费。

## 第二次优化核对（2026-10-04）

本轮按用户清单将新注册名限制为 10 字符，Django 最小密码长度由 12 调整为 8；其余框架密码校验、Argon2、邀请短事务、登录节流、CSRF、角色与会话机制继续使用。旧用户名和密码哈希未改；超过 10 字符的旧成员已通过真实 CSRF 登录回归，不强制重置。

## 第一次优化核对（2026-10-03）

新增欢迎/注册为公开入口，但加入家庭须有效管理员一次性邀请。Django 签名和 UserCreationForm 用于邀请校验、密码校验和哈希，SQLite IMMEDIATE 短事务防止同邀请重用；发行者禁用/降为非管理员时邀请不再有效。新增账号始终 member、非 staff，普通成员不能发邀请。家庭设置 GET 放开到已鉴权家庭成员，原管理员修改边界仍在。

YOLO 生产代码不加载 .pt/pickle、不执行模型返回文字、不调用视觉大模型或网络。只读取 data/models 下经散列、张量形状与类序校验的 ONNX，CPU 单并发两线程。管理员仍须可信获取模型；检查不能证明任意第三方 ONNX 无风险。仓库随附模型来自官方公开权重的固定词表导出，附 AGPL 许可及来源，不含真实家庭照片。页面用 textContent 显示候选，照片不持久保存，确认候选不写库存。模型未配置与图片失败均有真实降级。

回归中的邀请码、用户名、密码、照片样本均为隔离合成或公开数据。没有上传真实数据库、运行配置、Cookie、照片、CA 私钥或日志。当前 Caddy 服务检查为停止状态；本轮未改变 CA/防火墙/网段，未执行 Android 无警告 HTTPS 与相机系统选择器现场验收。旧手机证书警告不能记为已修复。
